# BT SHARE

BT SHARE is an experimental audio-sharing application project.

## Branch workflow

Development follows this promotion order:

1. Member feature branch (for Member 3: `Sihan-Member-3`)
2. `development`
3. `main`

Member 3 owns the MIC-only AI translation feasibility work. Feature changes must be reviewed and merged into `development` before they are considered for `main`.
